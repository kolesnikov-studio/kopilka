# Kopilka *(рабочее название)*

Кроссплатформенное **локальное** приложение учёта личных финансов. Бесплатное, оффлайн-first: все данные живут на устройстве пользователя, ни серверов, ни телеметрии.

## Ключевые свойства

- **Платформы:** Windows, Linux, Android (iOS — позже)
- **Технологии:** Flutter, Riverpod, SQLite (drift)
- **Данные:** только на устройстве; перенос между устройствами — через экспорт/импорт файла бэкапа
- **Обновления:** приложение проверяет новые версии на GitHub Releases по согласию пользователя и даёт ссылку на страницу релиза

## Загрузка

Готовые сборки (Windows: установщик и portable, Linux: AppImage, Android: APK) — в разделе [Releases](https://github.com/kolesnikov-studio/kopilka/releases).

## Сборка из исходников

Проект — стандартное Flutter-приложение:

```sh
flutter pub get
flutter analyze
flutter test
flutter build windows   # или apk / linux
```
