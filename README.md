# Kopilka *(рабочее название)*

Кроссплатформенное **локальное** приложение учёта личных финансов: Windows, Linux, Android. Бесплатное, оффлайн-first: все данные живут на устройстве пользователя — ни серверов, ни телеметрии, ни аналитики. Подходит тем, кто хочет вести личный бюджет без регистрации и без отправки данных куда-либо.

## Приватность

- Данные не покидают устройство. Сетевые запросы в приложении — только с вашего согласия (по умолчанию выключены): проверка обновлений и, отдельно, обновление курсов валют. Ни фоновых периодических запросов, ни телеметрии.
- Перенос данных между устройствами — вручную, файлом резервной копии.
- Ни телеметрии, ни аналитики, ни учётных записей.

## Возможности

- **Счета и категории** — наличные, банковский счёт, карта и другое; предустановленный набор категорий доходов и расходов.
- **Доход, расход, перевод** — список операций с фильтрами и поиском; быстрый ввод одной кнопкой «Добавить» с выбором типа операции (расход, доход, перевод).
- **Мультивалютность** — встроенный справочник из 157 валют ISO 4217, счета в разных валютах; курсы задаются вручную или обновляются из открытого источника (opt-in: по кнопке и при запуске приложения), есть базовая валюта со сменой и пересчётом; суммы форматируются по разрядности валюты.
- **Переводы между валютами** — две суммы с расчётным курсом; курс зачисления фиксируется в момент перевода и больше не меняется.
- **Отчёты** — общий баланс, расходы по категориям (донат), динамика доходов и расходов за 6 месяцев; всё показывается в базовой валюте с пометкой «по текущему курсу».
- **Бюджеты** — месячный лимит на категорию расходов с прогрессом и подсветкой превышения; лимиты в базовой валюте.
- **Резервные копии** — экспорт и импорт JSON-бэкапа (импорт читает старые версии формата и полностью заменяет данные), CSV-экспорт транзакций, автобэкап при каждом запуске (хранятся последние 10).
- **Импорт CSV** — разовый перенос операций из другого приложения: колонки файла сопоставляются с полями вручную, операции добавляются к существующим.
- **Интерфейс на русском и английском.**
- **Проверка обновлений** — по согласию: уведомление о новой версии и ссылка на страницу релиза; скачивание и установка — вручную.

## Ограничения

- Правка операций не поддерживается: операцию можно удалить и создать заново.
- Синхронизации между устройствами нет — перенос данных только файлом бэкапа.
- Фонового обновления курсов нет: онлайн-обновление — только вручную кнопкой и одним тихим обновлением при запуске, и только после явного включения в настройках.
- Сборки под iOS не распространяются.

## Сборка из исходников

Понадобится [Flutter SDK](https://docs.flutter.dev/get-started/install) (стабильный канал; CI собирает на 3.47.5):

```sh
flutter pub get
flutter gen-l10n
flutter analyze
flutter test
flutter build windows   # или apk / linux
```

## Архитектура в двух словах

- Flutter: UI на Riverpod → контроллеры → типизированные DAO над SQLite (drift); UI не обращается к базе напрямую.
- Деньги — целые числа в минорных единицах (копейки/центы), без float.
- Даты — в UTC; удаление записей — soft delete.
- Подробности — [ARCHITECTURE.md](ARCHITECTURE.md).
