# Kopilka
Kopilka — a cross-platform personal finance manager for tracking expenses, managing budgets, savings, and debts. Developed by Kolesnikov Studio.

Kopilka — кроссплатформенный менеджер личных финансов для учета расходов, управления бюджетом, сбережениями и долгами. Разработан студией Kolesnikov Studio.
