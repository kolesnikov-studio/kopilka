# Kopilka *(рабочее название)*

Кроссплатформенное **локальное** приложение учёта личных финансов: Windows, Linux, Android. Бесплатное, оффлайн-first: все данные живут на устройстве пользователя — ни серверов, ни телеметрии, ни аналитики. Подходит тем, кто хочет вести личный бюджет без регистрации и без отправки данных куда-либо.

## Приватность

- Данные не покидают устройство. Сетевые запросы в приложении — только с вашего согласия (по умолчанию выключены): проверка обновлений и, отдельно, обновление курсов валют. Ни фоновых периодических запросов, ни телеметрии.
- Локальные напоминания (opt-in) — уведомления формирует само устройство, без сети; включаются только по вашему согласию (баннер в разделе «Долги» или настройках).
- Перенос данных между устройствами — вручную, файлом резервной копии.
- Ни телеметрии, ни аналитики, ни учётных записей.

## Возможности

- **Счета и категории** — наличные, банковский счёт, карта и другое; предустановленный набор категорий доходов и расходов с иконками: своя иконка при создании и смена потом; ненужные предустановленные категории скрываются (возврат — в настройках), пользовательские пустые удаляются.
- **Накопительные счета** — флаг «Накопительный» с датой напоминания о процентах (по умолчанию — через месяц): счёт помечается бейджем, карточка-напоминание появляется на дашборде в день напоминания; проценты пользователь начисляет сам, переводом.
- **Долги** — кто, сколько, в какой валюте и к какому сроку; срок возврата с календарной просрочкой (красная с дня, следующего за сроком); гашение — платежом или связкой «перевод + платёж»; проценты/штраф задаются при создании и честно видны строкой переплаты; после полного гашения — чип «Погашен»; к долгу прикладывается фото или PDF-чек перевода.
- **Финансовые советы** — локальные карточки-подсказки на дашборде; первый — про неснижаемый остаток и проценты (появляется, когда на счёте лежит сумма; ведёт в форму накопительного счёта).
- **Локальные напоминания (opt-in)** — по желанию: уведомления в 09:00 в день напоминания о процентах или срока долга, о перерасходе плана (когда план по категории выполнен на 80% и более — не чаще раза в сутки) и об исполненном отложенном переводе; на Linux планирование платформой пока не поддерживается — накопившиеся напоминания показываются при запуске.
- **Доход, расход, перевод** — список операций с фильтрами и поиском (у операций с файлом — маркер вложения); быстрый ввод одной кнопкой «Добавить» с выбором типа операции (расход, доход, перевод).
- **Вложения к операциям** — фото или PDF-чек (до 10 МБ) прикрепляются к сохранённой операции: фото открывается в полноэкранном просмотре, для PDF показываются метаданные; файлы хранятся локально рядом с базой и в бэкап не входят. Чек перевода можно приложить и к гашению долга.
- **Мультивалютность** — встроенный справочник из 157 валют ISO 4217, счета в разных валютах; курсы задаются вручную или обновляются из открытого источника (opt-in: по кнопке и при запуске приложения), есть базовая валюта со сменой и пересчётом; суммы форматируются по разрядности валюты.
- **Переводы между валютами** — две суммы с расчётным курсом; курс зачисления фиксируется в момент перевода и больше не меняется.
- **Отложенные переводы** — галка «Отложить» в форме перевода с датой исполнения: перевод с сегодняшней датой исполняется при запуске приложения; секции «Ожидают» и «Исполнены» в разделе «Планирование»; комиссия за перевод списывается отдельным расходом в выбранную категорию.
- **Отчёты** — общий баланс, расходы по категориям (донат), динамика доходов и расходов за 6 месяцев; всё показывается в базовой валюте с пометкой «по текущему курсу». Счёт с флагом «не учитывать в балансе» (для накопительных счетов) не попадает в общий итог, его собственный баланс и история не меняются.
- **Бюджеты** — месячный лимит на категорию расходов с прогрессом и подсветкой превышения; лимиты в базовой валюте.
- **Планирование** — раздел «Планирование»: план доходов и расходов по категориям на период; факт, остаток и перерасход обновляются живьём, у идущего плана — бейдж «Идёт»; автобюджет — план расхода по среднему доходу закрытого месяца на желаемый срок, только по явному согласию.
- **Прогноз баланса** — карточка в разделе «Отчёты» на 1, 3, 6, 9 и 12 месяцев вперёд: до появления плана — по средним расходам, после — по плану.
- **Резервные копии** — экспорт и импорт JSON-бэкапа (формат несёт планы и отложенные переводы; импорт читает старые версии формата и полностью заменяет данные), CSV-экспорт транзакций, автобэкап при каждом запуске (хранятся последние 10). Бэкап не переносит файлы вложений (фото/PDF) — только их метаданные.
- **Импорт CSV** — разовый перенос операций из другого приложения: колонки файла сопоставляются с полями вручную, операции добавляются к существующим.
- **Темы оформления** — шесть цветовых пресетов плюс светлая/тёмная/системная основа; выбор применяется мгновенно и сохраняется между запусками.
- **Интерфейс на русском и английском.**
- **Проверка обновлений** — по согласию: уведомление о новой версии и ссылка на страницу релиза; скачивание и установка — вручную.

## Ограничения

- Правка операций не поддерживается: операцию можно удалить и создать заново.
- Синхронизации между устройствами нет — перенос данных только файлом бэкапа.
- Фонового обновления курсов нет: онлайн-обновление — только вручную кнопкой и одним тихим обновлением при запуске, и только после явного включения в настройках.
- Сборки под iOS не распространяются.

## Сборка из исходников

Понадобится [Flutter SDK](https://docs.flutter.dev/get-started/install) (стабильный канал; CI собирает на 3.47.5):

```sh
flutter pub get
flutter gen-l10n
flutter analyze
flutter test
flutter build windows   # или apk / linux
```

## Архитектура в двух словах

- Flutter: UI на Riverpod → контроллеры → типизированные DAO над SQLite (drift); UI не обращается к базе напрямую.
- Деньги — целые числа в минорных единицах (копейки/центы), без float.
- Даты — в UTC; удаление записей — soft delete.
- Подробности — [ARCHITECTURE.md](ARCHITECTURE.md).
