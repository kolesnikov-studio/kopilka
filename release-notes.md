Теперь в Копилке курсы валют можно обновлять из интернета, а операции — переносить из CSV.

- **Курсы из интернета** — по желанию: галочка в настройках включает обновление курсов валют из открытого бесплатного источника (без ключей и регистрации) по кнопке «Обновить сейчас» и одним тихим обновлением при запуске приложения. Приложение только загружает курсы — ничего не отправляет; фоновых запросов и телеметрии нет. Ручной ввод курса остаётся: без сети работают последние курсы.
- **Импорт CSV с маппингом колонок** — перенос операций из другого приложения: колонки файла сопоставляются с полями вручную, перед импортом — предупреждение о дублях; операции добавляются к уже заведённым.

Обновление бесплатное, данные совместимы: бэкапы v0.1–v0.3 импортируются без потерь.

**Полный список изменений:** https://github.com/kolesnikov-studio/kopilka/compare/v0.3.0...v0.4.0
